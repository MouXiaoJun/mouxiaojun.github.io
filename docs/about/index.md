## 核心优势

- **高并发与一致性设计**：系统级竞态分析（余额 / 库存 / 配额 / 奖励），落地「原子条件更新 + 幂等键 + 唯一约束 + 状态机 CAS」多层方案，能讲清每种方案的取舍边界
- **中台组件抽象**：从零设计可插拔任务引擎（注册表 + 观察者 + 适配器，新增业务类型只需实现 3 个接口方法）、状态机框架（Guard/Action 由调用方注入）、活动引擎，供多条业务线复用
- **第三方系统集成**：计费系统 / 支付宝商户能力 / 多厂商短信 / 微信·Steam·SDK 多渠道身份——统一适配器接口、签名鉴权、回调状态机、异步对账
- **出海与 0→1 交付**：独立完成 5 款海外 App 后端 + 后台，沉淀 GoFrame 项目模板供后续项目复用
- **AI 辅助研发流程**：写规格 → 指挥 AI 构建 → 审查产出 → 评估验收；为团队建立强制 cross-review、任务号绑定 commit 等纪律
- **开源实践**：[dict-trans](https://github.com/MouXiaoJun/go-design-pattern)（Go 数据字典翻译框架，Mulan PSL v2，36 测试 + 6 基准，核心零依赖）

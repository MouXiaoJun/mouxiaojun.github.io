# Go 设计模式 23 讲

23 个 GoF 设计模式在 Go 中的落地。每个模式一篇笔记（左侧栏导航），配套可编译示例代码在 [github.com/MouXiaoJun/go-design-pattern](https://github.com/MouXiaoJun/go-design-pattern)（`code/0N_name/`，`go build ./... && go test ./...` 全绿）。

## 创建型（5）

| 模式 | 一句话 |
|---|---|
| [单例模式](单例模式) | 全局唯一实例：饿汉 / 懒汉 / 双重检查 |
| [工厂模式](工厂模式) | 简单工厂 → 工厂方法 → 抽象工厂，以及 DI 容器 |
| [建造者模式](建造者模式) | 复杂对象分步构建，Go 里常被「函数式选项」替代 |
| [原型模式](原型模式) | 复制已有对象而非重新创建 |
| [抽象工厂模式](抽象工厂模式) | 工厂的工厂：创建一族相关对象 |

## 结构型（7）

| 模式 | 一句话 |
|---|---|
| [适配器模式](适配器模式) | 包装不兼容接口，类比 `http.HandlerFunc` |
| [桥接模式](桥接模式) | 抽象与实现两个维度独立变化 |
| [组合模式](组合模式) | 树形结构统一处理叶子与容器 |
| [装饰器模式](装饰器模式) | 动态叠加职责，Go 里就是 http 中间件 |
| [外观模式](外观模式) | 门面统一简化复杂子系统 |
| [享元模式](享元模式) | 共享细粒度对象省内存 |
| [代理模式](代理模式) | 替身控制访问：懒加载 / 缓存 / 权限 |

## 行为型（11）

| 模式 | 一句话 |
|---|---|
| [职责链模式](职责链模式) | 请求沿链传递直到被处理，Go 里就是中间件链 |
| [命令模式](命令模式) | 请求封装成对象，支持 undo / redo |
| [解释器模式](解释器模式) | 定义语法并求值（四则运算 AST） |
| [迭代器模式](迭代器模式) | 顺序访问聚合，Go 里常被 `range` / channel 替代 |
| [中介者模式](中介者模式) | 中枢协调对象间交互（聊天室） |
| [备忘录模式](备忘录模式) | 快照保存与恢复（编辑器撤销） |
| [观察者模式](观察者模式) | 一对多通知（channel 订阅） |
| [状态模式](状态模式) | 状态驱动行为（订单状态机） |
| [策略模式](策略模式) | 算法族可替换：接口 vs 函数类型传参 |
| [模板方法模式](模板方法模式) | 骨架固定步骤可变，Go 用嵌入 + 接口注入模拟 |
| [访问者模式](访问者模式) | 不改元素类增加新操作（含 type switch 对照） |

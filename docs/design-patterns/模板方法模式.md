# 模板方法模式 Template Method

> **核心思想：**固定一个算法/流程的骨架，把少数可变化步骤留给具体实现。

经典 Template Method 依赖继承，但 Go 没有类继承。Go 中更自然的实现是**组合 + 函数 Hook / 小接口**。

## 场景：统一导入流程

CSV、JSON、第三方 API 导入都遵循：

```text
读取 -> 解析 -> 校验 -> 保存 -> 统计
```

骨架固定，`读取/解析` 会变化。

```go
type Record struct {
    ID   string
    Name string
}

type Loader func(context.Context) ([]byte, error)
type Parser func([]byte) ([]Record, error)

type Importer struct {
    Load     Loader
    Parse    Parser
    Validate func(Record) error
    Save     func(context.Context, []Record) error
}

func (i Importer) Run(ctx context.Context) error {
    if i.Load == nil || i.Parse == nil || i.Save == nil {
        return errors.New("incomplete importer")
    }

    raw, err := i.Load(ctx)
    if err != nil {
        return fmt.Errorf("load: %w", err)
    }

    records, err := i.Parse(raw)
    if err != nil {
        return fmt.Errorf("parse: %w", err)
    }

    if i.Validate != nil {
        for index, record := range records {
            if err := i.Validate(record); err != nil {
                return fmt.Errorf("validate record %d: %w", index, err)
            }
        }
    }

    if err := i.Save(ctx, records); err != nil {
        return fmt.Errorf("save: %w", err)
    }
    return nil
}
```

CSV 版本：

```go
csvImporter := Importer{
    Load:  loadFromS3,
    Parse: parseCSV,
    Validate: validateUser,
    Save: userRepo.BatchCreate,
}
```

JSON 版本只替换 Loader/Parser。

## 为什么比“伪继承”更 Go

不要为了复刻 Java 写复杂的匿名嵌入 + 回调父类技巧。Go 的函数是一等值，小步骤直接用函数字段通常更清晰。

当 Hook 有多个方法或状态时，再升级成接口：

```go
type Source interface {
    Load(context.Context) ([]byte, error)
    Name() string
}
```

## 固定哪些步骤很重要

Template Method 的价值来自“骨架不可随意打乱”。如果每个实现连执行顺序都完全不同，那就不应该共享模板。

例如必须保证：

```text
Validate 永远在 Save 之前
```

应该由 `Run` 控制，而不是让 Hook 自己决定何时保存。

## 测试流程顺序

```go
func TestImporterOrder(t *testing.T) {
    var calls []string

    importer := Importer{
        Load: func(context.Context) ([]byte, error) {
            calls = append(calls, "load")
            return []byte("x"), nil
        },
        Parse: func([]byte) ([]Record, error) {
            calls = append(calls, "parse")
            return []Record{{ID: "1"}}, nil
        },
        Save: func(context.Context, []Record) error {
            calls = append(calls, "save")
            return nil
        },
    }

    _ = importer.Run(context.Background())
    // assert calls == [load parse save]
}
```

## Template Method vs Strategy

- Template Method：整体流程固定，开放部分步骤；
- Strategy：整个算法可以替换。

在 Go 里两者都可能用函数字段实现，还是看设计意图。

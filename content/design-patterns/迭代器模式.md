# 迭代器模式 Iterator

> **核心思想：**把“如何遍历集合”的细节隐藏起来，调用方只消费元素，而不关心数据来自 slice、分页 API、数据库游标还是生成器。

Go 1.23 以后标准库提供 `iter`，Iterator 在 Go 里终于有了更统一、语言化的表达。

## 最简单：`iter.Seq[T]`

```go
import "iter"

func EvenNumbers(max int) iter.Seq[int] {
    return func(yield func(int) bool) {
        for i := 0; i <= max; i += 2 {
            if !yield(i) {
                return
            }
        }
    }
}
```

调用：

```go
for n := range EvenNumbers(10) {
    fmt.Println(n)
}
```

调用方完全不知道元素是提前存在，还是边遍历边生成。

## 更实用：隐藏分页 API

第三方接口每页最多 100 条：

```go
type Page[T any] struct {
    Items      []T
    NextCursor string
}

type UserClient interface {
    List(ctx context.Context, cursor string, limit int) (Page[User], error)
}
```

可以提供 `iter.Seq2[User, error]`：

```go
func Users(ctx context.Context, client UserClient) iter.Seq2[User, error] {
    return func(yield func(User, error) bool) {
        cursor := ""

        for {
            page, err := client.List(ctx, cursor, 100)
            if err != nil {
                yield(User{}, err)
                return
            }

            for _, user := range page.Items {
                if !yield(user, nil) {
                    return
                }
            }

            if page.NextCursor == "" {
                return
            }
            cursor = page.NextCursor
        }
    }
}
```

调用方：

```go
for user, err := range Users(ctx, client) {
    if err != nil {
        return err
    }
    fmt.Println(user.ID)
}
```

分页、cursor、停止条件全部藏在 Iterator 内部。

## 提前 break 必须停止底层工作

```go
for user, err := range Users(ctx, client) {
    if err != nil { ... }
    if user.ID == target {
        break
    }
}
```

`yield` 返回 false 后 Iterator 要立刻 return，不能继续请求后续页面。

## Iterator 不意味着一定异步

不要为了“流式”就启动 goroutine + channel：

```go
func Users() <-chan User
```

channel iterator 会额外引入：

- goroutine 生命周期；
- cancel；
- backpressure；
- channel close；
- 泄漏风险。

如果只是同步懒遍历，`iter.Seq` 更轻。

## 什么时候适合

- 分页 API；
- 大数据集懒加载；
- 树/图遍历；
- 想让多种数据来源提供统一消费方式。

普通 slice 直接 `range` 已经是最好的 Iterator，不需要再包一层类型。

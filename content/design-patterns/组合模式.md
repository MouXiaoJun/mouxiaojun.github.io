# 组合模式 Composite

> **核心思想：**让“单个对象”和“一组对象”实现同一个接口，使调用方可以用同一种方式处理树形结构。

文件系统、组织树、菜单、权限树、评论树、任务 DAG 的局部树形视图都很适合这个思路。

## 场景：文件和目录统一计算大小

```go
type Node interface {
    Name() string
    Size() int64
}
```

叶子节点：

```go
type File struct {
    name string
    size int64
}

func (f File) Name() string { return f.name }
func (f File) Size() int64  { return f.size }
```

组合节点：

```go
type Directory struct {
    name     string
    children []Node
}

func NewDirectory(name string, children ...Node) *Directory {
    return &Directory{name: name, children: children}
}

func (d *Directory) Name() string { return d.name }

func (d *Directory) Size() int64 {
    var total int64
    for _, child := range d.children {
        total += child.Size()
    }
    return total
}

func (d *Directory) Add(child Node) {
    d.children = append(d.children, child)
}
```

使用：

```go
root := NewDirectory("app",
    File{name: "main.go", size: 1200},
    NewDirectory("internal",
        File{name: "service.go", size: 3200},
        File{name: "repo.go", size: 2400},
    ),
)

fmt.Println(root.Size()) // 6800
```

调用方不需要判断当前是 File 还是 Directory。

## 树遍历不要塞进每个业务方法

可以单独提供 Walk：

```go
func Walk(node Node, visit func(Node) error) error {
    if err := visit(node); err != nil {
        return err
    }

    dir, ok := node.(*Directory)
    if !ok {
        return nil
    }

    for _, child := range dir.children {
        if err := Walk(child, visit); err != nil {
            return err
        }
    }
    return nil
}
```

```go
err := Walk(root, func(node Node) error {
    fmt.Println(node.Name(), node.Size())
    return nil
})
```

## 现实工程的注意点

### 防止环

Composite 通常假设是树。如果 `Directory` 可以把祖先重新 Add 进来，就会无限递归。生产代码应在构建阶段限制结构，或者遍历时维护 visited。

### 大树递归深度

极深结构可以改用显式 stack 迭代，避免递归栈过深。

### 并发修改

如果目录结构会被并发修改，`children` 需要同步策略。更简单的做法往往是构建后视为不可变。

## 测试

```go
func TestDirectorySize(t *testing.T) {
    root := NewDirectory("root",
        File{name: "a", size: 10},
        NewDirectory("sub", File{name: "b", size: 20}),
    )

    if got := root.Size(); got != 30 {
        t.Fatalf("Size() = %d, want 30", got)
    }
}
```

## 什么时候适合

- 数据天然是 part-whole 树形关系；
- 叶子和容器有稳定的共同操作；
- 调用方不希望到处做类型判断。

如果叶子与容器根本没有共同语义，不要强行设计一个“万能 Node 接口”。
